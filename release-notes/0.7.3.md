# Release notes for libsbgnpy 0.7.3

## Security

- Reject redirects from the rendering web service. HTTP 307 and 308 responses could forward an uploaded SBGN document to another origin. Redirect responses could also be read before the image size limit was enforced. Rendering now raises `RenderError` for redirect responses and leaves any existing image unchanged.
- Add regression tests for HTTP 301, 302, 303, 307 and 308 responses, including responses which claim to contain a valid image.
- Update Soup Sieve from 2.10 to 4.1.3, fixing denial of service in selector matching and parsing ([GHSA-mmhr-3c5m-f64f](https://github.com/advisories/GHSA-mmhr-3c5m-f64f), [GHSA-7g44-g9rc-x53w](https://github.com/advisories/GHSA-7g44-g9rc-x53w), [GHSA-6655-6qjp-jx7x](https://github.com/advisories/GHSA-6655-6qjp-jx7x)). Update wcmatch to 12.0.4, which includes the filename matching denial of service fix in 11.2 ([GHSA-53pm-wgxf-c6qf](https://github.com/advisories/GHSA-53pm-wgxf-c6qf)). Both are development dependencies; explicit version floors prevent a fresh development installation from selecting vulnerable versions.
- Parse standalone render XML with the same strict parser as SBGN documents. Malformed XML raises `ParserError`, entity content is ignored and an encoding declaration cannot corrupt an already decoded string.
- Restrict XML model lookup to libsbgnpy bindings as defense in depth, excluding unrelated dataclasses loaded by an application.
- Pin workflow actions to immutable commits and update checkout to 7.0.1, setup-uv to 10.4.0 and deploy-pages to 5.0.1. Release branch synchronization supplies credentials only to its push instead of storing them in the checkout.

## Compatibility

- Python 3.11.5 or newer is required. This preserves the Python 3.11 to 3.15 support range while allowing every locked environment to use the patched Soup Sieve releases, which require at least Python 3.11.5.

## Dependencies and development

- Update runtime dependency floors to certifi 2026.11.20 and xsdata 26.11, and refresh the complete dependency lock.
- Update development tools, including bump-my-version 1.8.1, Ruff 0.17.6, ty 0.0.111, tox 4.67.16, tox-uv 1.37.9, Zensical 0.1.3 and mkdocstrings-python 2.0.11. Pre-commit uses the updated Ruff and ty versions.
- Use ty's renamed `incompatible-attribute-override` rule for the generated bindings.
- Preserve the public `Enum` behavior when generating bindings with xsdata 26.11, which otherwise changes their base class to `StrEnum`.
